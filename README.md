# Lexi — 英语词汇听说学习

围绕江苏译林教材（8A / 9A）的英语单词、短语、句式学习工具。纯前端、本地优先、无需登录，数据保存在本机浏览器。

## 功能

- **教材词汇**：内置译林 8A / 9A 课文词汇，按单元浏览学习
- **智能训练**：认识 → 跟读 → 拼写 → 选择，四步渐进，自动记录薄弱词
- **朗读**：美音 / 英音 × 女声 / 男声四种组合，可调节语速
- **练习模式**：3D 闪卡（翻转评分）、搭配拼图（结构配对）、5 步微冲刺（输入→跟读→练习→AI→小测）
- **个人导入**：从 TSV / JSON 文件导入自制词表
- **暗色主题** + 四种主题色（翡翠 / 莓果 / 靛蓝 / 珊瑚），字体大小可缩放
- **中英文界面切换**
- **离线可用**（PWA，数据保存在本机）

## 使用

1. 打开页面，选择教材与单元
2. 在「学习」页浏览词汇，点击朗读按钮听发音
3. 进入「练习」页选择练习模式
4. 在「复习」页查看 SRS 待复习与错题
5. 在「设置」页配置朗读偏好、主题色、字体大小

## 技术栈

React 18 + TypeScript + Vite + Tailwind CSS v4 + Zustand + Dexie.js（IndexedDB）

朗读：edge-tts（腾讯云 SCF 代理）+ Web Speech API 回退
